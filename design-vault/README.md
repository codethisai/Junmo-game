## 🧭 작성 원칙
1. **설계가 코드를 이끈다** — 여기서 정하고 → 코드로 구현
2. **입체성** — 캐릭터는 욕망·두려움·방어기제·목소리까지 (표면 설정 X)
3. **링크로 연결** — `[[캐릭터]]` `[[스테이지]]` `[[조건]]` 교차 참조
4. **코드와 동기화** — 실제 구현과 어긋나면 양쪽에 플래그
