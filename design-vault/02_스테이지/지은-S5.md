## 결정사항 (유저 확정)
- 무대 = **잠실**: 롯데월드(교복 대여 데이트) 실컷 → **석촌호수 벚꽃(골든아워) 고백.**
- **턴 수 = 24턴**(피날레라 두 배 널널하게). 고백 = **준모가 정면.** 재회 = **준모가 봄 약속 회수.**
- 엔딩 = **3갈래**(진/굿/배드), 진엔딩 느슨·배드 씁쓸.
- 핵심 소품 = **준모의 노트**(그동안 알게 된 지은의 시시콜콜을 적은 것) → 고백 증거물.

## 루트 심장 · 정서 곡선
- **심장**: 성취(박사)로만 봐지던 사람이, **성취 아닌 '그냥 나'로 사랑받기.** 무장해제(S4)는 '받는' 쪽 → S5는 지은이 **먼저 기대하기로 선택.**
- **곡선(5막)**: ①재회·어색 → ②교복·입장 → ③롯데월드 하하호호 → ④공백 회복(진심) → ⑤노을 벚꽃 고백.
- 톤: 진지 5 : 코미디 5. 롯데월드는 **신랄하게 재밌게**, 후반은 잔잔·애틋. **템포 낙차**(왁자지껄→고요)가 고백의 무기.

## 브릿지 — 애틋한 겨울 몽타주 (S5 진입 전)
```
컷1 (한 달 뒤)  짧은 안부 카톡, 둘 다 바빠 짧게 끊김
컷2 (두 달 뒤)  "언제 봐요" "그러게요" 흐지부지 / 지은이 답장 쓰다 지움(또 실망할까 봐)
컷3 (벚꽃)      준모가 먼저 벚꽃 사진 + "꽃 폈네요. 그때 그 약속, 아직 유효해요?" → S5
```
핵심: 지은의 '지웠다' = 공백이 무심 아니라 **못 다가간 것**(S4 T8 "기대하면 실망은 더 큰 법" 회수).

## 캐릭터 상태
- **지은**: 겨울 내내 매달린 **논문 최종 심사(디펜스) 막 통과.** 인생 최대 성취인데 **정작 허함**(부모는 성취만 축하 → 진짜 기뻐해줄 사람이 준모뿐). 겨울 공백의 명분이자 T19 터뜨릴 카드.
- **준모**: 회사 프로젝트 마무리하고 여유. 겨울 내내 생각했지만 서툴러 주저 → 벚꽃 보고 용기.

## 의상 여정 · 룩 · 에셋
```
재회(핑크 원피스, 낮)  →  교복 대여(롯데월드 내내)  →  피날레(핑크 원피스, 석촌호수 노을)
```
- **지은 사복** = 핑크 민소매 원피스 + 크림 가디건 + **긴 생머리 풀어 내림**(에셋 `jieun_smile/neutral/bored_s5` 기준). S4 슬릭번·환자 몰골 ↔ 화사 반전.
- **교복** = 롯데월드 대여(둘 다). 도도 박사 교복 갭 + 준모 사이즈 안 맞는 갭.
- **시간** = 롯데월드 낮→해질녘, **고백은 골든아워(노을)**. (밤 아님 — 배경 에셋이 노을)
- **에셋 현황**: ✅있음 `jieun_s5_seokchon_cherry`(석촌 벚꽃 노을) · `jieun_*_s5`(핑크 원피스 표정). ⚠️To-do: **교복 지은 표정셋 · 롯데월드 배경 몇 종 · 고백 CG · (선택)인생네컷·노트 소품컷.**

## 엔딩 3갈래 (진 느슨 · 배드 씁쓸)
| | 조건 | 내용 |
|---|---|---|
| 💕 진엔딩 「연인」 | 호감 상 **+ 검은순간(T22) 돌파 + 최종 이해테스트(T24) 정답** | 고백 성공→연인→에필로그. **노트 건넴 → "뒷장은 같이 써요".** |
| 🌸 굿엔딩 「봄, 다시」 | 호감 중 | 노트 보여주지만 아직 못 받음, "조금만 더 생각할게요" 여지 |
| 🥀 배드 「흩날리는」 | 호감 하 or 검은순간 실패 | 공백 못 넘고 **씁쓸하게** 흩어짐(노트 못 꺼냄) |
- **최종 이해테스트(T24)** = 성취 아닌 '시시한 나'를 짚는 선택일 때만 진엔딩. 틀리면 굿으로 강등.

## 엔진 정합 (호감도·엔딩·코드) ⚙️
> 엔진(`helpers.judge`)은 **최종 호감도 1개 값으로 5단계** 판정(호감도 50 시작·0~100캡). 별도 플래그 게이트 없음 → **게이트는 affChange 큰 스윙으로 구현.**

| tier | 호감도 | S5 엔딩(`stage.ends`) |
|---|---|---|
| great | ≥85 | 💕 진 「연인」 (고백 성공·노트·에필로그) |
| good | 70~84 | 🌸 굿 「봄, 다시」 (여지) |
| friend | 45~69 | 🥀 「좋은 사람」 (담백 아쉬움) |
| crush | 25~44 | 🥀 「흩날리는」 (씁쓸) |
| fail | <25 | 🥀 「남처럼」 (가장 씁쓸) |

**affChange 방침** (24턴·100캡이라 후반에 tier가 갈리도록):
- 일반·롯데월드(T1~16): 정답 **+2~+3** / 무난 +1~+2 / 지뢰 −2~−3 (완만)
- 공백 회복(T17~20): 정답 **+3~+4** / 지뢰 −3~−5
- 🌑 검은순간(T22): 정답 +5 / **오답 −12~−15** (tier 강등용)
- 고백·이해테스트(T23~24): 정답 **+6~+8** / 무난 +3 / **지뢰 −8~−10**
→ 잘 쌓고 + 검은순간 돌파 + 이해테스트 정답 = **진(≥85)**. 하나 실족=굿. 여러 실족·저조=그 아래.

## 핵심 연출 4
**ⓐ 준모의 노트** — S3에서 반쯤 꺼냈다 넣은 정체불명 노트 = 개발자 버릇대로 **그동안의 지은 시시콜콜을 적은 것**(『토지』·롯데 꼴찌·기형도·귤 실·배마즙…, 날짜·태그까지). S3 땐 "덜 완성돼서" 도로 넣음 → 이제 두꺼워짐. 고백 때 건넴 = **성취 아닌 시시한 나 전부를 본 물증.**
**ⓑ 검은 순간(T22)** — 분위기 최고조에 지은이 도망: "이대로도 좋지 않아요? 또 겨울처럼 될까 봐." 준모 오답(삐짐/추궁/밀어붙이기)→굿/배드 / 정답(공포 인정+"이번엔 안 놓을게요")→고백 돌파.
**ⓒ 고백·화답(T23~24)** — 준모 담백 정면 고백(성취 얘기 0). 지은 화답 = 눈물 왈칵 X, **도도한 채 항복**: 노트 넘기며 "…이걸 다.", 피식, 몰래 챙긴 **인생네컷 사진**(T12) 슬쩍 → **마주 안기며**(S4 등뒤 백허그↔정면) "이번엔 준모씨가 안 놓기로 한 거예요." 〔고백 CG〕
**ⓓ 에필로그** — 지은이 노트 **빈 뒷장에 자기 얘길 씀**(남 글만 읽던 사람이) + 재잘대는 카톡(겨울엔 뜸했던 창).

## 지뢰축 (S5)
겨울 공백 추궁·삐짐 / 관계 규정 조급하게 몰기 / 성취 프레임("박사님") / 신난 갭을 유난·애 취급 / 느끼한 작업멘트.
> 공통 정답: 공백 안 따지고 **지금** 채우기 · 성취 아닌 **시시한 나** 짚기.

## CG·연출·표정
- CG: ★필수 ①롯데월드 신남(만개 웃음) ②고백(노을 벚꽃, 마주 안은 둘+노트). ○여유 재회·에필로그(노트 뒷장).
