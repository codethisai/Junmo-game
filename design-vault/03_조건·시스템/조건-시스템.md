# 조건 · 시스템

> 게임을 움직이는 **규칙 엔진**. 호감도·표정·씬·엔딩이 어떤 조건으로 결정되는지. **현재 코드(`src/screens/GameScreen.jsx`) 기준** 정리 — 설계를 바꾸려면 여기서 먼저 정하고 코드 수정.
> 관련: [[세계관]] · [[지은]] · [[수아]] · [[유정]]

## 1. 호감도 → 표정 (현재)
`getCharacterExpression()`:
| 호감도(aff) | 표정 슬롯 |
|---|---|
| ≥ 70 | `smile` |
| 35 ~ 69 | `neutral` |
| < 35 | `bored` |

- 캐릭터 키 = `{prefix}_{표정}`. prefix: 유정=`yujung`, 수아=`sua`, 지은=`jieun`.
- **폴백 체인**: 해당표정 → 해당캐릭터 smile → 유정 같은표정 → 유정 smile → 안전 폴백(onError).
- ⚠️ **한계**: 표정이 smile/neutral/bored **3종 고정**. `surprised/emotional`(유정 S5) 같은 키는 **호출되지 않음** → 살리려면 이 로직 확장 필요.

## 2. 스테이지 → 씬 (현재)
`getSceneKey(partnerId, stageId, aff)`:
- **지은**: S1~S5 전용 씬 고정 (`JIEUN_S1_BOOKCAFE` … `JIEUN_S5_SEOKCHON`).
- **수아**: S1~S4 고정, **S5는 호감도 분기** (≥60 `NAMSAN_FINALE` / <60 `WINDOW_NIGHT`).
- **유정/공용**: 호감도로 분기 (예: S2 ≥50 낮 / <50 밤, S4 ≥60 낮 / <60 밤, S5 ≥70 테라스 / <70 식사).
- 전용 씬 없으면 공용 `S1_CAFE…`(유정 이미지)로 폴백.

## 3. 호감도 증감
- 선택지마다 `affChange` 값. 진심·경청 = 높음(+), 아는척·회피 = 낮음/마이너스.
- 예: [[지은-S4]]는 "이기려고 읽기"에 마이너스(-3~-6) 설계.

## 4. 엔딩 / 도전과제
- `jieun_clear` 📚 / `sua_clear` 🎤 / (유정 클리어) / `all_partners` 💌 삼각관계(3인 모두).
- 숨겨진 엔딩 4종 기획 존재(README 로드맵) — 상세 설계 필요.

## 5. 입체화 아이디어 (앞으로 설계할 것)
> 지금은 호감도 1축뿐. 더 입체적으로 만들려면:
- [ ] **표정 확장**: smile/neutral/bored 외 surprised/teary/blush 등 + 상황별 호출 로직
- [ ] **플래그/기억**: 특정 선택을 캐릭터가 "기억"해 후속 대사 변화
- [ ] **조건부 이벤트**: 스테이지 중 돌발 이벤트(침묵타이머·위기) 트리거 규칙
- [ ] **다축 관계 지표**: 호감 외 신뢰/긴장 등 보조 수치
- [ ] **CG 트리거**: 간파 CG 등 이벤트 컷을 특정 조건에서 노출
