**오프닝**: 시험기간 연세대 도서관. 논문 마감에 몰린 지은이, 처음으로 준모를 자기 영역으로 부른다.

## 1막 · 연세대 도서관 (밤샘)

**T1 — 그녀의 요새** (징크스·자리 규칙)
- **+3** "자리 지킴이 할게요. 커피 뽑으러 갔다 와요." → 지은: "…(옅게) 의외로 쓸모가 있군요."
- **+1** "오, 명당이네요." → 지은: "…그런 셈이죠."
- **−2** "창가가 집중 잘 되는데. 자리 바꿔봐요." → 지은: "훈수 두는 사람이, 저한테는 제일 방해돼요." *(경멸 눈빛)*

**T2 — 논문 속 그 사람** (소설 인물 감정이입=자기투영, 과몰입 갭)
- **+3** "걔가 뭐 잘못이라도 했어요? 이렇게 발끈하는 거 은근 드문데." → 지은: "답답하잖아요! …(가슴 탕탕) 사람 답답해 죽으라는 거지." *(소설이 답답한지, 현실이 답답한지)*
- **+1** "어떤 소설이에요?" → 지은: "재미로 보지는 않아요. 논문이라."
- **−2** "결국 인간의 욕망 뭐 그런 거죠?" → 지은: "…(펜 딱) 읽어보고 하는 말이에요, 지금?" *(아는 척 큰코)*

**T3 — 두 세계의 번역** ('읽고 쓰기' 공용어 심기→S5)
- **+3** "결국 읽고 고쳐 쓰는 일이에요. 지은씬 소설, 저는 코드." → 지은: "…우리 둘 다 남이 쓴 거 붙잡고 있는 거네." *(두 세계가 맞물린다)*
- **+1** "앱 만들고 오류 잡고… 뭐." → 지은: "…아, 네."
- **−2** "백엔드 API·CI/CD·쿠버네티스도—" → 지은: "…(멍하니) 대단하네요." *(지은이 싫어하는 말 되돌려받음=거울 지뢰)*

**T4 — 같이 일하는 침묵** (준모 개발자 눈으로 조력)
- **+3** "내용은 1도 모르겠고… 근데 여기 각주 번호 겹쳤어요." → 지은: "어. 진짜네. 그걸 어떻게 봤어요?"
- **+1** "뭐 도울 거 있어요?" → 지은: "이거 복사 좀. 양면으로."
- **−2** "이 문장 이렇게 고치면 더 있어 보이지 않아요?" → 지은: "제 문장은 제가 알아서 해볼게요."

**T5 — 엄마** (부모 압박 복선 심기→S4 / ⚠️첫 진짜 화)
- **+3** "괜찮아요? …커피 식었네, 새로 뽑아 올게요." → 지은: "…네. 괜찮아요." *(캐묻지도 못 본 척도 않음)*
- **+1** (못 본 척 자료 넘김) → *(굳은 얼굴이 뇌리에 남는다)*
- **−4** "부모님이세요? 기대가 크신가 봐요, 박사까지 하시는 거 보면." → 지은: "…(날카롭게) 그런 이야기를 제가 했었나요? 왜 이렇게 눈치가 없어요." *(처음으로 진짜 화)*

**T6 — 도피처** (기형도=결핍 반半고백, 준모가 '결핍'을 처음 알아챔)
- **+3** "이건 소설 아니죠? 시도 읽어요?" → 지은: "힘들 때 읽어요. 이 사람만큼 결핍을 정확히 쓰는 사람이 없거든요." / 준모: "결핍이요…?" *(이제 그녀 말마다 결핍이 겹쳐 보인다)*
- **+1** "깊이 있으시다." → 지은: "…(시집 넣으며) 가끔요."
- **−2** "기형도, 요절해서 미화된 것도 있죠." → 지은: "…역시, 아무한테나 보여줄 게 아니었네." *(도피처 도로 닫음)*

**T7 — 읽는 자, 지은** (관찰 역전→S4 '읽히는 공포' 전제)
- **+3** "아 들켰다.. 지은씨 앞이라 더 그런 거 같기도." → 지은: "…(멈칫) 보통은 우기는데.." *(정곡 찔려도 웃어버리니 지은이 말문 막힘)*
- **+1** "제가요? 아닌데요." → 지은: "…아니면 말고요."
- **−2** "지은씨야말로 남 분석 좋아하잖아요. 방어기제래요." → 지은: "…(눈이 식으며) 아는 척, 진짜 별로예요." *(역분석 지뢰)*

**T8 — 삼각김밥 세 끼** (성취 뒤 초라한 '그냥 지은' + 준모 씩씩한 챙김)
- **+3** "그거 내려놓고 일어나요. 감자탕집 가서 한 그릇, 내가 살 테니까." → 지은: "…(퀭한 눈) 네… 그래요…" *(갈려나간 몰골 / 감자탕 한 그릇 뚝딱, 얼굴에 핏기가 돈다)*
- **+1** "밥은 좀 챙겨 먹지." → 지은: "…이따가요, 이따."
- **−2** "삼각김밥이라니ㅋㅋ 의외로 소탈하시다." → 지은: "소탈이 아니라 시간이 없는 거예요." *(초라함을 소탈로 포장=갭 소비)*

## 2막 · 감자탕집 → 도서관

**T9 — 아껴둔 책** (S1 T8 복선 연장, '때가 될 때' 미룸→S4 전달)
- **+3** (책 반쯤 꺼냈다 도로) "이건 때가 될 때, 제대로 줄게요." → 지은: "…뭔데요, 꺼내다 말면 더 궁금하잖아요."
- **+1** (그냥 넣으며) "아니에요, 아무것도." → *(아무 일도 없던 일이 됐다)*
- **−2** "제가 진짜 아끼는 책인데… 읽으면 제가 완전 이해될걸요? 인생 책이라—" → 지은: (어색하게 눈 돌림) *(선물이 짐이 된다=생색)*

## 3막 · 찜질방 (새벽)

**T10 — 실컷 놀기** (양머리 갭 + 오락기 승부욕 폭발)
- **+4** "내기하죠. 진 사람이 식혜 쏘기." → 지은: "…(소매 걷어붙이며) 좋아요, 후회나 마요." *(쾅! 점수 치솟고 벼락 효과음, 지은 눈 확 뒤집힘 — 낮의 서늘하던 모습은 없다)*
- **+2** "구경할게요, 해봐요." → 지은: "혼자 하면 재미없는데." *(흥이 금세 식음)*
- **−2** "이런 데 오니까 우리 사귀는 것 같지 않아요?" → 지은: "자꾸 그런 저질 소리 할래요? 됐어요, 저 잘래요." *(급하게 들이댐)*

**T11 — 새벽 네 시, 온기** `S3 피날레` (서늘한 돌바닥+전기장판, 붙어 새근새근·손X)
- **+5** "꼭 자야 되나요. 이러고 있는 것도 나쁘지 않은데." → *새어드는 빛·선선한 공기·전기장판 온기 속, 나란히 눈 뜨고 누움 → 지은 고개가 스르르 기울어 어깨에 닿음 → 준모 가만히 받음 → 그냥 따뜻하다 → 새근새근 잠듦.* *(아무것도 안 해도 되는 밤. 이 사람 옆이 딱 그렇다.)*
- **+3** "눈 좀 붙여요. 옆에 있을게요." → 지은: "…고마워요, 오늘." *(손 뻗으면 닿을 거리에서 그냥 잠듦)*
- **−2** (돌아누우며) "우리 이제 좀 정리해요, 무슨 사이인지—" → 지은: "…(눈 감은 채) 그 얘긴 나중에요. 지금은 조용히." *(좋던 정적을 말로 깸)*
