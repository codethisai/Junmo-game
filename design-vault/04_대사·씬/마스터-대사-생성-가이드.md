## 0. 이 게임이 뭐냐 (30초 요약)
- **AI 소개팅 시뮬 비주얼노벨.** 플레이어 = 강준모(29·모태솔로·IT개발자·진솔하지만 서툼).
- 히로인 3인 × **5스테이지(S1~5)** × **11턴** × 턴당 **선택지 3개**(피날레는 4개 가능).

- 재미의 핵심 = **"이 히로인이 뭘 좋아하고 싫어하는지 추리해서 맞히는" 공략 게임.**

## 1. 절대 진실 소스 (헷갈리면 이걸 따른다)
- 캐릭터 = **각 바이블([[지은]] v3, [[유정]], [[수아]])이 정본.** ⚠️ [[세계관]] 표는 구버전(지은을 '석사/INFJ/조용·진솔'로 적음) → **무시.** 정본: 지은 = **박사과정 / INTJ / 도도 쿨데레.**

- ❌ **폐기된 것**: "염미정/은희경/김애란" 문학 톤(너무 튐), 지은 S2~5의 기존 염미정 패스. → 유키노(오레가이루) 도도 쿨데레 + 현실 한국 여자 말투로 재작성.

## 2. 구조 스펙 (모든 스크립트 공통)

```js
export const {KEY} = {           // 예: JIEUN_S1
  partnerId: "{id}",             // jieun / yumi(유정!) / sua  ⚠️유정 id는 yumi, 이미지 prefix는 yujung
  stageId: {n},
  opening: "장면 도입 내레이션 + 히로인 첫 대사",
  turns: [
    { turn: 1, scene: "장면 지문(직전 상황 1~2줄, 히로인 대사 포함 가능)", choices: [
      { text: "준모 선택지 대사", response: `{이름}: "..."\n준모 속마음: ...`, affChange: N },
      // 3개 (피날레는 4개 허용)
    ]},
    // ...11턴
  ],
};
```

- **response 형식**: `{이름}: "대사"` + `\n` + `준모 속마음: 관찰/감정`. (필요시 지문은 `(괄호)`로 대사 안에.)
- **상태 표시**(피날레 분기 등)는 `*이탤릭*` 한 줄로 추가 → 게임 렌더러가 흐린 이탤릭으로 표시(`GameScreen.jsx` fmt).
- ⚠️ **response 안 준모 대사는 원칙적으로 금지**(§4-3). 단, 의도된 "대화 죽는 정적" 연출 등 예외는 명시적으로만.

### affChange 곡선 (페이싱)
| 구간 | 정답 | 무난 | 지뢰 |
|---|---|---|---|
| S1 초반(T1~3) | +2~+4 | +1~+2 | −1~−2 |
| 중반(T4~8) | +3~+4 | +1~+2 | −1~−2 |
| 후반/피날레(T9~11) | +4~+5 | +2~+3 | −1~−2(치명적 실수는 −2) |

> **한 턴에 승부내지 마라.** 2턴 만에 고호감 = 긴장 죽음(수아 T7 실패 사례). 명장면·깊은 통찰은 신뢰 쌓인 T6+에.

## 3. 선택지 설계 5법칙 (공략의 재미)
1. **셋 다 진짜 그럴듯해야 한다.** "정답 1 + 바보 2"는 티 나서 실패. 셋 다 "실제로 누가 할 법한 말."
2. **정답/오답은 '캐릭터 이해'로 갈린다.** 대놓고 좋은 말 X. 그 캐릭터의 지뢰·트리거를 아는 사람만 고를 수 있게.
3. **직전 대사를 받는다.** 방금 히로인이 한 말/행동에 반응. 붕 뜬 선택지(동문서답) 금지.
4. **오답 = '무례/바보'가 아니라 '이 사람한텐 안 통함'.** 그럴듯한데 이 캐릭터 결과 미묘하게 어긋난 것.
5. **단서를 심어라.** 히로인이 싫어하는 걸 대사·지문으로 미리 흘려서, 플레이어가 추리하게.

## 3.5 ⭐ 소재는 가볍게, 진전은 확실하게 (최상위 원칙 · 2026-07-18 유저 확정)
> 지금까지 대사가 계속 어긋난 진짜 이유. 유저가 "바로 이거"라고 확정한 결.

- **얼마 안 만난 이성끼리다.** 논문·문학·이별·가족 같은 **무거운 소재는 양념 한 스푼만.** 메인은 **시시콜콜 취향 잡담** — 실제 소개팅처럼: 야구·만화·맛집·주말·음식·취향.
- **단, 시시콜콜하되 확실하게.** 가볍게 말해도 **매 턴 델타·진전은 그대로** 있어야 함. (잡담만 오가면 '정보 교환', 진전이 있어야 '장면')
- **갭 디테일로 캐릭터를 살려라.** 예: 도도한 국문학 박사 지은이 사실 **롯데(만년 꼴찌) 팬** / 준모는 야구장보다 **만화방**. *의외의 시시한 취향*이 사람을 생생하게 한다.
- **무거운 코어 비트는 '플리커'로.** 진짜 무거운 순간(삼킴·상처·고백)은 대화 내내 붙잡지 말고 **한 번 훅 들어왔다 빠지는** 식으로 짧게. 무거움을 오래 끌면 소개팅이 상담이 된다.
- **정답/지뢰도 이 결로**: 정답=성취·무게로 안 가두고 **시시한 걸 시시하게 반김** / 지뢰=**성취 프레임으로 가두기**("박사님 대단"), **성급히 데이트 코스로 몰기**.
- **유저 지시 = 참고지 명령이 아니다.** 세부 지시를 다 기계적으로 반영하면 글이 어색해진다. **방향만 참고하고 자연스러움을 우선**해 판단. (예: "눈 피하는 묘사" 지시 → 직접 서술 대신 볕·바람·머리칼 같은 환경으로 둥글게. 서술은 직접적이지 않게 둥글둥글.)

## 4. 대사 작법 (캐릭터 '맛' 살리기)

### 4-1. 준모 속마음 (가장 자주 망가지는 곳)
- ❌ **결론·해석·콘셉트 선언**: "답을 기다리는 눈치다" / "외로운 사람이구나" / "취향 확실한 사람"
- ✅ **관찰·신체감각·감정만**: "말끝이 살짝 올라갔다" / "잔 쥔 손이 굳는다" / "이상하게 눈이 안 떼진다"
- ❌ **메아리 금지**: 직전 대사 단어를 되풀이(대사 "침묵" → 속마음 "침묵으로…").
- ✅ **여운형**: 직설("오늘 나한테 폈다") 대신 서브텍스트("비로소 내비친다").
- 표기: "안 ~한다"보다 **"~하지 않는다"** 온전한 형태. 위치어 "앞/안에서"보다 **"속에서"** 선호.

### 4-2. 준모 정답 대사
- **수동 금지** ("저도요", "재밌는데요"). **능동·의미 담긴·심쿵**으로.
- 드라마 명장면 느낌(선수 쳐서 다음 약속 만들기, 상대 감정 알아채기).
- 모호한 지시어("그게 더 좋아요 — 뭐가?") 금지 → 대상 명확히.
- **자연 구어.** 각 잡힌 문어체·잠언 금지.

### 4-3. response 안 준모 자동대사
- 준모 목소리는 **선택지(text)로만.** response의 자동 대사는 플레이어 페르소나와 충돌.
- 예외: **의도적 "대화 죽는 정적"** 같은 연출(지은 S1 T11 ③) — 이땐 명시적으로.

### 4-4. 지뢰 선택지 (리얼리티 — 이번 세션 핵심 교훈)
- **캐리커처 금지.** "저 좋아하죠? 솔직히 말해봐요" 급 노골적 대사는 아무도 안 고름 → 게임성 0.
- **실제로 흔히 하는 미묘한 실수**로. (예: 먼저 온 연락을 관심으로 못 읽고 "무슨 일인데요?"로 되받아 대화 말려 죽이기 / 재는 척 튕겨 상대 용기 무안하게 만들기)
- 결과는 **정적·어색·물꼬 마름**처럼 현실적으로. 속마음으로 **자기가 망친 줄도 모르는 대비**(웃음+교훈).

### 4-5. 급전개·소재 금지
- S1에 "오늘부터 1일"·"우리(커플 전제)"·"말 안 해도 안 불편" = 실패. 감정은 쌓여야 한다.
- 과거사·외로움 갑툭튀 금지. **깔아둔 뒤 후반에 터뜨리기**(복선 회수).

---

### 4-6. 준모 '어른 대화' voice (2026-07 세션 — 중요)
- **다 설명·다 답하는 '애새끼' 금지.** 감정 브리핑 X → 툭 던지고 여백. 묻는 거에 다 답 말고 받아치거나 흘리기.
- **안 퍼주면 상대가 온다 (자존감).** 정답=여유(절제) / 지뢰=애씀(확인강박·훅·코스 짜기).
- **상대 톤에 맞춰라.** 지은이 건조하면 같이 건조하게. 혼자 가슴 열지 말기.

### 4-7. 금지 표현·습관 (누적)
- **"어, 그거 『토지』" 식 오프너/직접 명명 금지** → 오blique하게 ("다 읽으셨나 보네요").
- **"무난한 X가 무난하게"** 패턴 금지 / **"한 칸 닫힌다"** 류 상투 금지.
- **한 턴 안에서 같은 단어 반복 금지** (예: "뭐" 여러 번).
- **완성도 ≠ 긴 소설체.** 턴은 길어도 되나 **게임 호흡·현실 대화** 유지, 안 끊기게.
- **철학·인생관은 대사로 설명 말고** 행동+한 줄로 oblique하게 (짜치지 않게).

### 4-8. 이번 세션 적립 (2026-07-26 지은 S4)
- **"~말고" 식 미완결 종결 남발 금지** → 완결형("~하지 말아요"). 문장 끝을 흐리지 말 것.
- **"발갛게" 대신 "벌겋게"** (열·홍조 묘사).
- **속마음: 큰틀(감정 축)은 살리되 앞질러 '해설'하지 말 것.** ❌ "아무 데도 못 도망가게 한다"·"옆에 있는 사람 얘기처럼 들린다"(작가 결론) → ✅ 담백한 관찰·신체("귀는 못 가렸다"·"이불깃을 코끝까지 끌어당긴다"). *감정은 히로인 대사가 지고, 속마음은 관찰만.* (단 밋밋하게 큰틀까지 날리면 안 됨 — 둘은 다르다.)
- **턴마다 구체적 '시시콜콜 소재' 하나씩 박기** (S3식): 자리징크스·소설과몰입·각주번호… / S4=죽·장조림·롯데·귤·해열패치·배마즙. 소재 위에 감정을 얹어야 붕 안 뜬다.
- **승부처(피날레) 히트 라인은 야무지게 하나로.** 도도 캐릭터는 직접 고백보다 **가정법·못 한 말·말없는 행동(백허그)**이 더 설렌다. 말로만 설레게 X, 진짜 설레게.
- **(S5 적립) 지문·오프닝에 라노벨식 상투 포즈 금지**('손잡이를 잡고 서서' 류 = 짜침) → 담백하게. 대신 **구체적 숫자·디테일**("13일에 한 번, 21일에 한 번", 노점·상인·구경거리)로 **쏠쏠한 리얼리티.** 스크립트는 매 줄 '의미'가 없어도 됨 — 소소한 재미가 오히려 살린다.
- **(작업법 — 막힐 때 '다른 주제 변주' 대량 생성)**: 한 문장/한 비트에서 유저가 "다시"를 반복하면, 같은 문장 미세수정 말고 **서로 결·주제가 다른 버전을 10개씩 배치로** 뽑아 방향을 고르게 한다(수미상관/유머/여운/정적/독백회수 등 각기 다른 앵글). 유저가 고른 결로 확정. 배치는 10개씩 끊어 질 유지.
- **(S5 확정 종합 — 지은/준모 말투 표준 · 유저 반복 확정)**:
  - **지은은 "듣기 좋으라고 해주는 예쁜 말"을 안 한다.** 속으로 설레도 겉은 **툭 던지는 자기 할 말**(핀잔·팩폭·정정)로. 말 따로 행동 따로(대사는 시큰둥, 손은 안 뺌)의 갭이 지은다움. ❌"끝까지 안 놓네요 준모씨"(예쁜 말) → ✅"총 쏠 땐 손 하나 안 떨더니"(툭).
  - **행동으로 승부, 대사는 최소.** 큰 감정일수록 대사 걷어내고 **행동 한 컷**(손·눈·키스)으로. 접촉·정지의 순간은 **느리게 늘려** 설렘을 만든다(노골 X, '느림'에서 설렘).
  - **'말에 대한 말' 금지**("가볍게 대답 안 할게요", "오래 볼 사람한테 하는 말로")=공허. 다짐·약속을 추상적으로 말하지 말고 **구체적 행동/증거(노트 등)**로 보여라.
  - **레퍼런스는 바이브만, 절대 설명·인용 X**(초속5cm·러브레터·데미안·어바웃타임 → 제목/장면/대사 직접 언급 금지, 정서만 은근히).
  - **소재 회수 강박 금지**(롯데·귤 억지로 갖다붙이면 신파·촌스러움). 필요할 때만 자연스럽게.
  - 표현 디테일: "안 ~" 줄임보다 완결형, 불필요한 "좀/안" 남발 금지, 어미 반복 금지, 모호한 지시어 금지.
- **(S5 T22 순애 독백 톤 — 클라이맥스 표준)**: 담백한데 문학적. **과설명·뇌절 금지, 여백(…)으로 호흡.** 은유는 **하나만, 쉽게**(알 깨는 새/데미안). 큰 감정일수록 **문장은 짧고 낮게.** 고백은 크게 외치지 말고 **툭 착지**("평생을 이렇게 살아왔어요. 이제 솔직해지고 싶어요. …고마워요. 그리고, 좋아해요."). 자기연민·미화 X, 방어기제도 **행동으로**(밀어냄) 보이되 담담히. → **클라이맥스·고백 턴은 이 톤 기준.**
- **(S5 적립·누적) ① 진짜 사람 말투 최우선**: 설명조·읊기(영화 장면 나열 등) 금지, 감정은 subtext로. **레퍼런스는 '바이브'만 은근히**(제목·유명 대사 직접 인용 X, 심하면 아예 뺀다). **② 어미·표현 남용 금지**('~건데'·'~말고' 반복 / '왜 그랬대요' 류 유치·응석 말투 금지 → 건조·존댓말). **③ 대사 트리밍**(사족 빼고 짧게, 여백). **④ 속마음**은 담백 관찰 기본이나 맥락상 **히로인 심정 직접 짚기도 허용**('속마음이 훤히 들여다보인다'), 큰틀 감정은 유지. **⑤ 지뢰 강도 조절**(가벼운 삐끗 OK, 단 코어=성취 프레임 정통타는 강하게) · **무난도 진전**. **⑥ 지은=롯데 팬 → 야구 메타(3 OUT 등) 잘 붙음.**

## 5. 캐릭터 치트시트 (입에 붙이기)

### 🌸 유정 (ENFP · 브랜드 마케터 · `yumi`/img `yujung`) — 자연스러움 기준작
- **결**: 밝고 편한 분위기메이커, 리액션 좋고 먼저 다가감. 속바람 = "진짜 들어주는 사람."

- 💢 폰·건성 단답·자기 얘기만·겉도는 칭찬·성급한 정의 → 바로 식음.

- 갭: 밝은 뒤에 "혼자 떠들까 봐" 긴장. 볼 붉어짐.

## 9. 🏆 정답 대사 은행 (골드 예시)
> 유저가 "퀄 좋다"고 확정한 실제 대사. 앞으로 이 결로.

**[지은 S3 T3 · 두 세계 번역]** — 준모(개발)를 *그녀의 언어*로 번역해 공용어를 만든다.
> 준모: "결국 읽고 고쳐 쓰는 일이에요. 지은씨가 소설 읽고 논문 쓰듯이, 저는 코드 읽고 고쳐 쓰고."
> 지은: "…(살짝 흥미) 그럼 우리 둘 다, 하루 종일 남이 쓴 거 붙잡고 있는 거네."
> 속마음: 완전히 다른 두 세계가, '읽고 쓰는 일'에서 잠깐 맞물린다.
- **왜 좋나**: 전문용어 0으로 **상대 언어로 번역** → 공용어('읽고 쓰기') 탄생. 거울 지뢰(전문용어 자랑 "CI/CD·쿠버네티스…")와 대비가 선명.

**[지은 S3 T2 · 과몰입 갭]** — 소설 인물을 실존 인물처럼 욕하는 지은(=자기투영), 준모는 가볍게 받아줌.
> 준모: "걔가 지은씨한테 뭐 잘못이라도 했어요? 이렇게 발끈하는 거, 은근 드문데."
> 지은: "답답하잖아요! …(탕탕, 가슴을 치며) 아주 사람 답답해 죽으라는 거지."
> 속마음: 소설이 답답한 건지, 현실이 답답한 건지 알 길이 없다.
- **왜 좋나**: 깊은 결핍을 **설명 없이** 과몰입 갭(가슴 탕탕)으로만. 도도한 박사의 갭모에 + 자기투영 플리커.

**[지은 S4 T5 · 도로 끌어다 얹는 손]** — 준모가 열 재고 떼려는 손을, 지은이 붙잡아 제 이마에 다시 얹는다.
> 지은: "(일어서려는 준모의 손목을 잡는다. 떼어낸 손을 제 이마에 다시 지긋이 올리며) …차갑다. 좀만, 이러고 있어요."
> 속마음: 오랜만의 온기가 그녀의 이마에 머문다.
- **왜 좋나**: 무장해제를 대사 아닌 **행동**으로. 도도한 사람이 '가지 말라' 대신 손을 끌어다 얹는 갭.

**[지은 S4 T11 · 말없는 백허그]** — 준 썸 피날레. 고백(S5)은 유보하고, 못 하는 말을 등 뒤 포옹으로.
> 준모: "다 나으면 연락해요. 그때… 다시 만나요."
> 지은: "(등 뒤로 가만히 안긴다) …오늘 고마웠어요. (등에 이마를 묻는다)"
- **왜 좋나**: 도도 캐릭터의 최대 설렘 = **말없는 행동.** 고백을 성급히 못박지 않고(=지뢰) 여운으로 다음 스테이지 훅.
