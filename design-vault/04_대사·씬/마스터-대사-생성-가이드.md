## 0. 이 게임이 뭐냐 (30초 요약)
- **AI 소개팅 시뮬 비주얼노벨.** 플레이어 = 강준모(29·모태솔로·IT개발자·진솔하지만 서툼).
- 히로인 3인 × **5스테이지(S1~5)** × **11턴** × 턴당 **선택지 3개**(피날레는 4개 가능).
- 대화 본진 = **스크립트 파일** `src/data/script_{id}_s{n}.js`. (Groq LLM 실시간은 보조 → §7)
- 재미의 핵심 = **"이 히로인이 뭘 좋아하고 싫어하는지 추리해서 맞히는" 공략 게임.**

## 1. 절대 진실 소스 (헷갈리면 이걸 따른다)
- 캐릭터 = **각 바이블([[지은]] v3, [[유정]], [[수아]])이 정본.** ⚠️ [[세계관]] 표는 구버전(지은을 '석사/INFJ/조용·진솔'로 적음) → **무시.** 정본: 지은 = **박사과정 / INTJ / 도도 쿨데레.**
- 톤 기준작 = **유정 S1~5(자연스러움) + 지은 S1(도도 캐릭터성).**
- ❌ **폐기된 것**: "염미정/은희경/김애란" 문학 톤(너무 튐), 지은 S2~5의 기존 염미정 패스. → 유키노(오레가이루) 도도 쿨데레 + 현실 한국 여자 말투로 재작성.

## 2. 구조 스펙 (모든 스크립트 공통)

```js
export const {KEY} = {           // 예: JIEUN_S1
  partnerId: "{id}",             // jieun / yumi(유정!) / sua  ⚠️유정 id는 yumi, 이미지 prefix는 yujung
  stageId: {n},
  opening: "장면 도입 내레이션 + 히로인 첫 대사",
  turns: [
    { turn: 1, scene: "장면 지문(직전 상황 1~2줄, 히로인 대사 포함 가능)", choices: [
      { text: "준모 선택지 대사", response: `{이름}: "..."\n준모 속마음: ...`, affChange: N },
      // 3개 (피날레는 4개 허용)
    ]},
    // ...11턴
  ],
};
```

- **response 형식**: `{이름}: "대사"` + `\n` + `준모 속마음: 관찰/감정`. (필요시 지문은 `(괄호)`로 대사 안에.)
- **상태 표시**(피날레 분기 등)는 `*이탤릭*` 한 줄로 추가 → 게임 렌더러가 흐린 이탤릭으로 표시(`GameScreen.jsx` fmt).
- ⚠️ **response 안 준모 대사는 원칙적으로 금지**(§4-3). 단, 의도된 "대화 죽는 정적" 연출 등 예외는 명시적으로만.

### affChange 곡선 (페이싱)
| 구간 | 정답 | 무난 | 지뢰 |
|---|---|---|---|
| S1 초반(T1~3) | +2~+4 | +1~+2 | −1~−2 |
| 중반(T4~8) | +3~+4 | +1~+2 | −1~−2 |
| 후반/피날레(T9~11) | +4~+5 | +2~+3 | −1~−2(치명적 실수는 −2) |

> **한 턴에 승부내지 마라.** 2턴 만에 고호감 = 긴장 죽음(수아 T7 실패 사례). 명장면·깊은 통찰은 신뢰 쌓인 T6+에.

## 3. 선택지 설계 5법칙 (공략의 재미)
1. **셋 다 진짜 그럴듯해야 한다.** "정답 1 + 바보 2"는 티 나서 실패. 셋 다 "실제로 누가 할 법한 말."
2. **정답/오답은 '캐릭터 이해'로 갈린다.** 대놓고 좋은 말 X. 그 캐릭터의 지뢰·트리거를 아는 사람만 고를 수 있게.
3. **직전 대사를 받는다.** 방금 히로인이 한 말/행동에 반응. 붕 뜬 선택지(동문서답) 금지.
4. **오답 = '무례/바보'가 아니라 '이 사람한텐 안 통함'.** 그럴듯한데 이 캐릭터 결과 미묘하게 어긋난 것.
5. **단서를 심어라.** 히로인이 싫어하는 걸 대사·지문으로 미리 흘려서, 플레이어가 추리하게.

## 4. 대사 작법 (캐릭터 '맛' 살리기)

### 4-1. 준모 속마음 (가장 자주 망가지는 곳)
- ❌ **결론·해석·콘셉트 선언**: "답을 기다리는 눈치다" / "외로운 사람이구나" / "취향 확실한 사람"
- ✅ **관찰·신체감각·감정만**: "말끝이 살짝 올라갔다" / "잔 쥔 손이 굳는다" / "이상하게 눈이 안 떼진다"
- ❌ **메아리 금지**: 직전 대사 단어를 되풀이(대사 "침묵" → 속마음 "침묵으로…").
- ✅ **여운형**: 직설("오늘 나한테 폈다") 대신 서브텍스트("비로소 내비친다").
- 표기: "안 ~한다"보다 **"~하지 않는다"** 온전한 형태. 위치어 "앞/안에서"보다 **"속에서"** 선호.

### 4-2. 준모 정답 대사
- **수동 금지** ("저도요", "재밌는데요"). **능동·의미 담긴·심쿵**으로.
- 드라마 명장면 느낌(선수 쳐서 다음 약속 만들기, 상대 감정 알아채기).
- 모호한 지시어("그게 더 좋아요 — 뭐가?") 금지 → 대상 명확히.
- **자연 구어.** 각 잡힌 문어체·잠언 금지.

### 4-3. response 안 준모 자동대사
- 준모 목소리는 **선택지(text)로만.** response의 자동 대사는 플레이어 페르소나와 충돌.
- 예외: **의도적 "대화 죽는 정적"** 같은 연출(지은 S1 T11 ③) — 이땐 명시적으로.

### 4-4. 지뢰 선택지 (리얼리티 — 이번 세션 핵심 교훈)
- **캐리커처 금지.** "저 좋아하죠? 솔직히 말해봐요" 급 노골적 대사는 아무도 안 고름 → 게임성 0.
- **실제로 흔히 하는 미묘한 실수**로. (예: 먼저 온 연락을 관심으로 못 읽고 "무슨 일인데요?"로 되받아 대화 말려 죽이기 / 재는 척 튕겨 상대 용기 무안하게 만들기)
- 결과는 **정적·어색·물꼬 마름**처럼 현실적으로. 속마음으로 **자기가 망친 줄도 모르는 대비**(웃음+교훈).

### 4-5. 급전개·소재 금지
- S1에 "오늘부터 1일"·"우리(커플 전제)"·"말 안 해도 안 불편" = 실패. 감정은 쌓여야 한다.
- 과거사·외로움 갑툭튀 금지. **깔아둔 뒤 후반에 터뜨리기**(복선 회수).

## 5. 캐릭터 치트시트 (입에 붙이기)

### 🌸 유정 (ENFP · 브랜드 마케터 · `yumi`/img `yujung`) — 자연스러움 기준작
- **결**: 밝고 편한 분위기메이커, 리액션 좋고 먼저 다가감. 속바람 = "진짜 들어주는 사람."
- ❤️ **공감 > 유머 > 외모.** 잘 듣고 맞장구·자연스런 유머.
- 💢 폰·건성 단답·자기 얘기만·겉도는 칭찬·성급한 정의 → 바로 식음.
- 시그니처 구어: "에이 아무거나가 어딨어요", "듣는 척 말고 진짜 들어주는", "나오길 잘했다."
- 갭: 밝은 뒤에 "혼자 떠들까 봐" 긴장. 볼 붉어짐.

### 📚 지은 (INTJ · 국문학 박사과정 · `jieun`) — 도도 쿨데레
- **결**: 유키노(오레가이루) 도도 쿨데레 + 현실 20대. 논문에 지침. **성취 말고 '그냥 나'를 봐줄 때 흔들림.**
- ❤️ **솔직한 무지**("그 시인 몰라요, 알려줘요") · 진짜 아는 것으로 지적 대등 · 눈치.
- 💢 **아는 척 · 작업멘트 · 외모칭찬 · 성급함.**
- 목소리: 팩트 정정 버릇("정확히는…"), "글쎄요", 건조한 팩폭, **잘 안 웃음**(피식=이벤트), 존댓말 "준모씨".
- 지문: 잔·컵 가장자리 만지작(긴장 신호). 갭: 술 약함(반 잔에 볼 빨개짐).
- 호감 3단(지문으로만): 소=정정 안 함 / 중=먼저 질문 / 대=피식.
- 소재: 기형도 시 덕질(도피처), 박경리 『토지』(S1 소재).

### 🎤 수아 (ESFP · 인플루언서 28만 · `sua`) — 화려한 가면 뒤 외로움
- **결**: 카메라 앞 화려, 끄면 혼자. 매 순간 콘텐츠화. 지루함=죽음.
- ❤️ **텐션 > 외모 > 유머.** 같이 신나주고 리액션 받아주기.
- 💢 억지로 맞추는 척(바로 알아챔)·폰·자기세계 갇힌 사람 → 30분 만에 이탈.
- 목소리: 에너지 폭발·즉흥·감탄사("어, 진짜요?!"). **높은 호감에서만** 텐션 내려놓고 진솔.
- 호칭: S1 "준모씨"+존대 / S2+ "오빠"·반말. "당신" 금지.
- 대비축: **수아=보여지고 싶은데 외로움 / 지은=안 보여지고 싶은데 읽힘** (정반대).

## 6. ✅ 셀프 체크 루브릭 (유저에게 보여주기 전에 내가 먼저 통과시킨다)
> 이 통과가 "수정 없는 자동화"의 핵심. 초안을 쓰고 아래를 스스로 채점, 3점↑ 항목 있으면 고쳐서 낸다.

**턴 단위:**
- [ ] 선택지 3개 다 그럴듯한가? 정답이 캐릭터 이해 없이 뻔한가?(뻔하면 실패)
- [ ] 직전 히로인 대사를 받는가?
- [ ] 지뢰가 캐리커처 아닌 '실제 있을 법한 미묘한 실수'인가?
- [ ] 속마음이 결론/메아리 아닌 관찰·감정·여운인가?
- [ ] 준모 정답이 수동 아닌 능동·심쿵인가? 모호한 지시어 없나?
- [ ] affChange가 구간 곡선에 맞나?(초반 과다 금지)

**스테이지 단위:**
- [ ] 캐릭터 바이블(핵심심리·목소리·트리거) 안 깨졌나?
- [ ] 장소·룩이 바이블 스테이지 표와 일치하나?
- [ ] 정서 곡선(어색→편해짐→통함→여운)이 평탄하지 않나?
- [ ] 명장면·깊은 대사가 후반(T6+)에 있나?
- [ ] 반복 표현 없나? 한국어만? 유행어·오글 없나?
- [ ] 복선(앞에 깔고 뒤에 회수)이 있나?

## 7. LLM 실시간 대화(보조)와의 연결
- 스크립트가 본진이지만, Groq 실시간도 같은 캐릭터를 말한다. 프롬프트 빌더 `buildSys()`(`src/utils/helpers.js`).
- **§5 치트시트 = buildSys의 `[캐릭터]`/`[현재 장면 연기 지시]`/`[말투 예시]` 슬롯 재료.** 스크립트 재작성 시 나온 good/bad 대사를 few-shot으로 재활용.
- 미해결: 장소 데이터 불일치(`partners.js.stages` ≠ 정본) → [[대화-프롬프트-설계]] ②. 재작성 때 같이 교정.

## 8. 작업 방식 (맛은 사람, 손·검증은 AI)
1. **내가 셀프 체크(§6) 통과한 완성본**을 턴 단위(또는 소단위)로 제시.
2. 유저 검수·수정 → 반영.
3. **코드(`script_*.js`) + 확정본 문서(`04_대사·씬/{캐릭터}-S{n}-대사-확정본.md`) 동시 갱신** (동기화 필수).
4. 새로 배운 규칙은 이 가이드에 즉시 반영(누적).
