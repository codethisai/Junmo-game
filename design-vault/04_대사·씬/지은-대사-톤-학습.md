## 방향 (대전제)
- **현실성 소개팅 게임.** 대단한 서사 X. 문학·심오함 X.
- **모솔 찐따가 어려워하는, 세련된 20대 한국 여자.** 미연시 캐릭터성은 **한 스푼만.**
- 소개팅은 **하나의 감정 서사가 아니라, 이 얘기 저 얘기 오가는 잡담.** (화제: MBTI·주말·음식·술·이상형·연애 등)
- 캐릭터 레퍼런스: **유키노(오레가이루, 도도 쿨데레)** 태도 + 현실 한국 여자 말투. ⚠️ 문학(염미정·은희경·김애른)은 **폐기**(너무 튐).

## 확정 설정
- 지은: 논문에 지친 국문학 박사과정. 소개팅은 **지쳐서 억지로 나옴**, 준모를 **탐색 중**.
- 장소: 조용한 북카페.
- 공략 — 호감↑: 편하고 센스 있는 대화 / 안 재고 솔직 / 눈치 빠름. 호감↓: 작업멘트 / 억지로 웃기려 함 / 아는 척 / 눈치 없음.

## 학습된 톤 (1~8차)
1. **곧이곧대로 답 안 함** — 무심하게 비껴가며 여운
2. **짧고 담백이 기본** — 사족(부연·설명·위트) 매번 붙이면 과함
3. **위트·구체 디테일은 가끔 한 스푼** — 매턴 X
4. **은근한 자신감·도도** — 구체 디테일로 툭 (예: "소주 두 병까진 멀쩡")
5. **상대를 슬쩍 관찰하는 위트** (예: "방금 살짝 실망한 표정인데")
6. **캐릭터는 의외의 구체 디테일로** (예: "논문 시즌엔 삼각김밥 세 끼")
7. **귀여운 갭모에** = 씹덕 설렘 (예: "저 맵찔이예요")

**회피**: 처량한 자조 / 밋밋한 정보성 답 / 작위적 반전 / 과한 밀당·역공 / 공격적 팩폭 / 뻔한 자조 / 사족.

## 통과한 대사 샘플 (정답지)
- MBTI: "그런 거 잘 안 믿는데." / "방금 살짝 실망한 표정인데."
- 주말: "쉬는 날이 있었나. 기억이 안 나네요."
- 음식: "논문 시즌엔 편의점 삼각김밥으로 세 끼 버텨요." / "저 맵찔이예요. 이런 거로 정 떨어지는 사람 은근 많던데."
- 술: "소주 두 병까진 멀쩡해요. 이런 얘기 하면 다들 좀 긴장하던데."
- 이상형: "말 잘 되는 사람이요." (사족 없이)

## 유정에서 배운 기법 (S1 학습 완료 · 2026-07-12)
유정 대사가 자연스러운 이유 = 아래 7가지. **기법은 그대로, 톤만 지은 것(도도·담백)으로.**
1. **자연스러운 구어** — "에이 아무거나가 어딨어요" 급. 애니체 0.
2. **구체 디테일로 캐릭터 생생** — 인스타 카페탐방·한강 돗자리·샤잠. (지은판 = 삼각김밥·맵찔이)
3. **캐릭터 코어가 대사에 자연스럽게** — 유정 "듣는 척 말고 진짜 들어주는".
4. **선택지 지뢰 명확 = 게임성** — 폰·건성·겉도는칭찬 = 호감↓. 캐릭터 이해로 갈림.
5. **은근한 감정 흐름** — 각 턴은 잡담인데 전체는 *어색→편해짐→통함→설렘* 상승. (⚠️ 나는 화제 오가기만 하려다 이 흐름·생생함을 놓침)
6. **씹덕 설렘 디테일** — "나오길 잘했다", "볼 붉어짐", "흘린 말을 기억해준 게 닿았다".
7. **속마음 = 관찰·감정** (결론 X).

> **핵심 교훈**: 잡담(화제) + 은근한 감정 흐름 + 캐릭터 생생함을 **동시에.** 화제만 오가면 뻣뻣, 감정서사만 하면 무겁다. 둘의 균형이 유정의 자연스러움.

## ⭐ 지은 말투 정답지 20선 (fable 제공 · 골드 스탠다드)
> 앞으로 지은 대사는 **이 결로만.** 내가 뽑은 것보다 이게 기준.

**기본 (도도·탐색 모드) — S1 초반 디폴트**
1. "글쎄요. 그건 만나보고 판단할 일 아닌가요."
2. "아, 정확히는 박사과정이에요. 박사 아니고. …다들 헷갈리시더라고요."
3. "재밌는 일 하시네요. 저는 재미없는 일 해요."
4. "소개팅 많이 해보셨어요? …아니구나. 티 나요."
5. "그 질문, 오늘 세 번째예요. 제 답은 아직 같고요."
6. "시 전공이라고 하면 다들 낭만적이라 그러는데. 낭만은 마감 없는 사람들 거예요."
7. "칭찬이에요, 그거? 어떤 의도인지 몰라서 일단 보류할게요."
8. "괜찮아요. 어색한 건 준모 씨 잘못 아니에요. 소개팅이라는 제도 잘못이지."
9. "…와인은 제가 시킬게요. 고르는 거 보고 있기가 좀 그래서."
10. "똑똑하다는 말은 됐어요. 그거 말고 다른 거 없어요?"

**팩폭·위트 모드**
11. "방금 그거, 기형도가 아니라 윤동주예요. …뭐, 몰라도 사는 데 지장은 없어요."
12. "거짓말은 아닌데 정확하지도 않네요. 준모 씨 화법이 좀 그래요."
13. "웃기려고 한 말이에요? …아. 그럼 반쯤 성공했어요."
14. "저 술 세 보인다는 말, 오늘 처음 들어요. 그리고 틀렸어요."

**호감 상승 후 (정정 안 함 → 먼저 질문 → 살짝 열림) — 후반만!**
15. "…아뇨, 계속하세요. 듣고 있었어요."
16. "그건 좀… 아니에요, 넘어가요. 중요한 거 아니니까." *(정정하다 마는 = E3 변주 = 호감)*
17. "준모 씨는요? 아까부터 저만 대답하고 있는 것 같은데." *(K2 먼저 질문 = 호감)*
18. "그 얘기 조금만 더 해봐요. 처음 듣는 얘기라."
19. "기형도 몰라도 돼요. …근데 알고 싶다고 하면, 한 권 빌려줄 수는 있어요." *(G 트리거 회수)*
20. "오늘 생각보다… 아니에요. 다음엔 커피 말고 딴 거 마셔요. 뭐, 그런 데서." *(F3 마지막 열림)*

### ⚠️ 규칙 (안 지키면 또 망함)
- **말끝 자르거나(…) 정정하다 마는 게 = 호감 신호.** (16, 20)
- **15~20을 기본으로 오해 금지.** 기본 = 1~14(도도·팩폭). **S1 초반은 무조건 도도.** 열림은 지문·말끝으로만 조금씩.

## ✍️ S1 다듬기 세션 룰 (2026-07-17 · 유저 피드백 누적 — 앞으로 이 기준으로 수정)

**노선**
- S1은 **문학 심오함 노선 유지**(잡담 전환 X). 단, 추상적 문학론 X → **구체 작품·구절로 의미 있는 대화.** (예: 박경리 『토지』 서희 광복 장면 / 기형도 『입 속의 검은 잎』 「엄마 걱정」 "나는 찬밥처럼 방에 담겨")

**준모 정답(호감↑) 대사**
- **수동적 답변 금지** ("저도요", "재밌는데요" 류). **능동적·의미 담긴·러블리·심쿵**으로.
- 드라마 명장면 느낌(선수 쳐서 다음 약속 만들기, 상대 감정 알아채기 등).
- "그게(뭐가?)" 모호한 지시어 금지 → **대상 명확히.**
- 문장 **딱딱하지 않게, 자연 구어.**

**지은 반응**
- **사족 앞부분 자르고 짧게.** (예: "그 행에서 멈춘 거, 눈치챘어요?" → "눈치챘어요?")
- 지뢰 선택 땐 지은이 **직접 위트로 되받아 게임성** 살리기 (예: "맛집 리스트만 보고 배부르다는 거랑 똑같은데").
- 인정은 반 톤 낮춰 도도하게 ("아무나 못 하는 독법이에요" / "재밌는 표현이에요").

**속마음(내레이션)**
- "안 ~한다" 축약 대신 **"~하지 않는다"** 온전한 형태. ("눈을 안 피한다" → "눈을 피하지 않는다")
- 위치 표현 **"앞에서/안에서" 보다 "속에서"** 선호.
- 직설적 결론("오늘 나한테 폈다") 대신 **여운 있는 관찰**("비로소 내비친다").
- 씹덕 설렘 디테일: 귀 붉어짐 · 손끝 스침 · 처음 보는 미소.

**지뢰 선택지 (리얼리티)**
- **캐리커처 금지.** "저 좋아하죠? 솔직히 말해봐요" 같은 노골적 대사는 아무도 안 고름 → 게임성 X.
- **실제로 흔히 하는 미묘한 실수**로. (예: 먼저 온 연락을 관심으로 못 읽고 "무슨 일인데요?"로 되받아 대화 말려 죽이기 / 재는 척 튕겨서 상대 용기 무안하게 만들기)
- 지뢰 결과는 **정적·어색·물꼬 마름**처럼 현실적으로. 준모 속마음으로 **자기가 망친 줄도 모르는 대비**(웃음+교훈).

**피날레 턴 (게임성)**
- 마지막 턴은 **선택마다 진로(루트)가 분기** — 예: 🟢다음 약속 확정 / 🟡관계 정체 / 🔴기회 상실.
- 각 선택에 **실제 연애에 통하는 원리**를 담되 설명체 X, 속마음·상태로 자연스럽게.
- 필요 시 선택지 3개 → 4개로 늘려 분기 다양화. affChange 폭도 넓게(+5 ~ −2).

**진행 현황**: **S1·S2 재작성 완료 ✅** (확정본: [[지은-S1-대사-확정본]] · [[지은-S2-대사-확정본]]) · S3~S5 미다듬. S2는 1부 숲길→2부 사직(롯데) 2막 구조. 애틋한 겨울 몽타주는 S4→S5 사이 예정.
