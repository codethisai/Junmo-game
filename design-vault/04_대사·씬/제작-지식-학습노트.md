# 📚 제작 지식 학습노트 (VN·게임 작법 정독 종합)

> 2026-08-07 세션: 대사·구조·연출·배포 20편+ 정독 학습. 대사 핵심은 [[알맹이-턴-작법]]·[[마스터-대사-생성-가이드]]에 별도 적립. 이 문서 = 그 외 영역 종합.
> 원칙: 우리는 **스크립트 100% 고정**(실시간 LLM 배제) → '작가가 좋은 대본 쓰기' + '배포로 반응 보기'에 초점.

## 1. 오프닝 훅 (S1 첫인상)
- **정보 쏟기(info-dump) 금지 → 캐릭터 반응 극화 + 질문 남기기.**
- 우리에 맞는 훅: **모순 감정**("억지로 나온 시큰둥함 밑에 뭔가") · **내재된 문제**(소개팅 자체) · **캐릭터 훅**(장면으로 각인).
- 첫 5분에 안 잡으면 이탈 → S1이 승부.

## 2. 캐릭터 첫 등장
- **외모 X → defining trait(정의적 특성)를 행동 한 컷으로.** ("예쁜 지은" < "『토지』 읽다 시큰둥하게 올려다보는 지은")
- **버릇/mannerism 일찍**(지은 잔 만지작·"정확히는") = 즉각 각인 서명.
- **첫인상 오도(mislead) 가능**: 도도해 보이지만 사실은… (반전 씨앗).
- 다른 인물이 먼저 언급(지도교수)하면 등장 임팩트↑.

## 3. 감정 페이싱 (정서 곡선)
- **긴장-이완의 파도**: 빠른 뒤 느린 게 와야 서로 도드라짐. (S5 롯데월드 왁자 → 벚꽃 고요 ✅)
- **최대 강도 계속 = 페이싱 아님, 그냥 시끄러움.** 감정 남발 금지(="말에 대한 말" 함정과 연결).
- **씬 길이 섞기**: 짧은 턴(긴박)·긴 턴(깊이) 교대 → 리듬·예측불가.
- **처진 중반(saggy middle) 주의**: S2·S3가 리스크 → 파도로 방지.

## 4. 유머 작법 (롯데월드·밴터)
- **코믹 타이밍 = 펀치라인 위치**(멈칫·"…"으로 쌓고 터뜨림).
- **밴터 구조**: A가 깔고 → B가 비틀어 되받기(지은 팩폭 ✅).
- **캐릭터 기반 코미디**(도도·허당 갭). 억지 밈 금지.
- **유머도 알맹이**: 웃긴 턴도 드러남/진전 있어야(그냥 웃기려고 X).

## 5. 사운드/BGM (stages.js bgm 필드 활용)
- BGM = 감정 강조·몰입. 루프 이음새 없이 + Start/Loop/End 스팅어로 전환.
- **침묵의 힘 ⭐**: "울어라" 바이올린·"중요해" 피아노 남발 = 값싸짐 → **결정적 순간엔 BGM 죽이기.**
- 지은 루트 톤용 bgm 지정 여지.

## 6. 온보딩 (배포=첫 판이 생명)
- 튜토리얼 짧게·텍스트 최소. **하면서 배우게.**
- **초반 Win-State**: 정답 고르면 +뜨고 지은 반응 → 유능감. 첫 턴에 "선택=관계 변화" 체감.
- **빛나는 선택(glowing choice)**: 첫 선택 은근 유도.
- 우리는 '소개팅'이라 룰 직관적(강점).

## 7. 분기 구조 (이론 진단)
- 우리 구조 = **Ladder(선택 흩뿌림) + Points(호감 임계 엔딩) + Gauntlet(지뢰=배드)** = 교과서 3대 패턴 정확히 사용 ✅. 조합폭발은 points로 관리 ✅.
- **확장 아이디어(나중)**: True Route(3명 다 클리어 시 보너스 엔딩) · Common Route(공통 프롤로그로 3인 소개) · Persistent Variables(완료 기록 잠금해제).

## 8. UI/UX·모바일 이탈 (배포 실무)
- **모바일 3초 룰**: 3초 내 로딩 안 되면 53% 이탈. UX 실패 시 이탈 70~90%. → **첫 로딩 속도가 배포 성패.**
- 텍스트 가독성 = VN 기본(명암 대비·폰트·여백 1/3).
- 모바일 특화(터치 우선). 데스크톱 축소판은 전환 12%↓.
- ⚠️ 실제 렌더 확인 필요(폰 테스트) → 그 뒤 코드 수정.

## 9. 종합 결론
- **대사 품질(알맹이) + 캐릭터 균등 + 현실 톤** = 한국 미연시 3대 지뢰(오글설정·메인몰빵·구린대본) 회피 ✅.
- 우리가 감으로 하던 것 대부분이 **이론으로 검증됨.** 남은 실전 리스크 = ①초반 알맹이 감사 ②수아 보강 ③모바일 첫인상(로딩·가독성).
