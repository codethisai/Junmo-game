# 루트 설계 템플릿 (세븐킹덤 방식 적용) 🎬

> 세븐킹덤 작가의 실제 작업 방식을 우리 게임에 이식. **대본을 바로 쓰지 않고, 먼저 '루트 설계'부터.**
> 재작성 실패 = 설계 없이 문장부터 손댐. 이 문서가 그 앞단(설계)을 채운다.
> 관련: [[참고-세븐킹덤-AI워크플로우]] · [[선택지-대사-설계]] · [[지은]] [[수아]] [[유정]]

---

## 🔑 세븐킹덤 작가의 실전 4단계 (스샷 근거)

1. **바이블 기억**: 커스텀 에이전트(Gem)에 캐릭터 바이블 로드. "이 캐릭터 얼마나 기억해?"로 시작해 기준 정렬.
2. **문제를 언어화해 던짐**: "이 서사를 N화 안에 끝내야 하는데 이건 미연시니까 감정이 메인 → **무게 배분이 필요해**", "이 캐릭터 트리거는 X인데 그 위기 사건을 뭘로 할지 고민" — 친구에게 던지듯 제약·고민을 말로.
3. **AI가 구조로 답**: **무게 배분(예: 정치 30% : 로맨스 70%)** + 에피소드별 **[상황(무대) / 감정(메인) / 포인트]**.
4. **작가 검수**: 별5개 될 때까지 + 본인이 디테일 수정.

> 예시(제로 루트): Ep1 빗나간 칼끝(Plot40:Rom60) → Ep2 버려진 도구(20:80) → Ep3 반역과 구원(50:50) → Ep4 처음 느끼는 온도(5:95) → Epi 백조의 호수(20:80). **정치는 "왜 다치고·흔들리고·안기는가"의 무대 장치로만.**

---

## 🎯 우리 게임 치환 (강준모의 소개팅)

우리는 정치 서사가 없다. 우리 두 축은:

- **상황/공략(SITUATION)** = 장소·사건·긴장. "이 턴에 뭘 겪나, 뭘 맞혀야 하나."
- **감정/설렘(ROMANCE)** = 호감 아크. "관계가 어디서 어디로 움직이나."

**스테이지 = 에피소드.** 히로인당 S1~S5. 무게 배분은 **S1(간보기·상황 높음) → S5(감정 폭발·로맨스 높음)** 상승 곡선.

### 루트 설계 표 (히로인마다 작성)

| 스테 | 제목 | 무게(상황:로맨스) | 상황(무대) | 감정(메인 아크) | 포인트(연출·게임성) |
|---|---|---|---|---|---|
| S1 | 첫 만남 | 60:40 | 장소·첫 대면 사건 | 낮음→간보기 | 캐릭터 지뢰/트리거 힌트 심기 |
| S2 |  | 50:50 |  | 간보기→편해짐 |  |
| S3 |  | 40:60 |  | 편해짐→가면 균열 |  |
| S4 |  | 30:70 |  | 흔들림·시험 |  |
| S5 | 피날레 | 20:80 |  | 해방·고백 | 비주얼 클라이맥스 |

> 숫자는 캐릭터마다 조정. 수아는 텐션 무대가 많고, 지은은 침묵·관찰 무대가 많다.

## 🛠 진행 절차 (우리 버전)

1. **바이블 정렬**: [[개발-서사-원천]] + 해당 캐릭터 시트를 기준으로 로드. "이 캐릭터 핵심 = 욕망/두려움/지뢰/트리거" 확인부터.
2. **문제 언어화 (준모)**: "S3에서 수아 가면이 처음 균열나야 하는데, 그 계기 사건을 뭘로?" 식으로 제약·고민을 말로 던진다.
3. **루트 설계 (구조)**: 위 표를 채운다 — 스테별 무게 배분 + 상황/감정/포인트. **대사는 아직 안 씀.**
4. **설계 검수 (준모)**: 무게·아크·포인트가 맞는지. 여기서 OK 나야 다음.
5. **대사 초안**: [[선택지-대사-설계]] 규칙으로. **초안=맛(사람/다른 AI), 검증=클로드.**
6. **스크립트화·배치**.

> 핵심 전환: **"문장부터 고치기"(실패) → "설계표부터 합의하기"(세븐킹덤 방식).**
