## Phase 0 — 정지작업 (재작성 전 1회, 半나절)
> 재작성이 헛돌지 않게 기준부터 못박는다.
1. **[[세계관]] 표 교정**: 지은 '석사/INFJ/조용·진솔' → '박사과정/INTJ/도도 쿨데레'. (바이블 v3와 불일치 제거)
2. **장소 정본 확정**: 각 바이블 스테이지 표 = 정본. 수아 장소 3중 불일치([[대화-프롬프트-설계]]②) 정리.
3. **확정본 문서 골격 생성**: `지은-S2~S5`, `수아-S1~S5` 대사 확정본 md 껍데기(현재 스크립트 미러) 만들어 두기.
4. 산출: 이 표를 "정본"으로 고정. 이후 모든 작업이 여기서 출발.

## Phase 1 — 지은 S2~S5 재작성 (최우선)
> 이유: 바이블이 **명시적으로 폐기 선언**한 염미정 톤. 톤 충돌이 가장 큼. S1 골드스탠다드 있으니 결 잡혀 있음.
- 순서: **S2 → S3 → S4 → S5** (감정 아크 순서대로: 편해짐→그녀 영역→방어 균열→해방).
- 스테별 루프:
  1. 바이블 스테 정서곡선 + [[마스터-대사-생성-가이드]] §5 지은 치트시트 확인.
  2. 11턴 초안 작성 → **§6 셀프체크 통과** → 턴 단위로 유저 검수.
  3. 확정 → `script_jieun_s{n}.js` + `지은-S{n}-대사-확정본.md` 동기화.
  4. S4·S5는 **기존 서사(간파·무장해제)가 기준작**이라 톤만 유키노로, 구조는 보존.
- ⚠️ 복선: S1에 깔린 것(기형도 시집·'아껴둔 책'·다음 약속) S2에서 회수 이어가기.
- 예상: 스테당 약 1세션(턴별 검수 포함). 총 4세션 안팎.

## Phase 2 — 수아 S1~S5 보강
> 재작성까진 아니고, 신규 룰로 **감사(audit) 후 필요한 턴만 수정.**
- 스테별: [[마스터-대사-생성-가이드]] §6 루브릭으로 11턴 훑어 3점↑만 손봄.
- 집중 점검: 초반 affChange 과다 / 지뢰 캐리커처 / 텐션 유지(높은 호감 전엔 가면) / 장소 정합.
- 확정본 md 동시 갱신.
- 예상: 스테당 반세션(문제 턴만). 총 2~3세션.

## Phase 3 — 유정 검증
> 기준작이지만 신규 루브릭으로 가볍게 재검. 거의 수정 없을 것으로 예상.
- §6 스테이지 단위 체크만. 발견 시 소폭 수정.
- 예상: 1세션 이하.

## Phase 4 — LLM 프롬프트 반영 (선택·후속)
> 스크립트에서 나온 good/bad 대사를 실시간 대화 품질로 환류.
- §5 치트시트 + 스테별 few-shot → `buildSys()` `[캐릭터]`/`[연기 지시]`/`[말투 예시]` 슬롯 보강.
- 장소 버그(`partners.js.stages`) 교정 동반.
- 예상: 별도 1~2세션 (코드 작업).
