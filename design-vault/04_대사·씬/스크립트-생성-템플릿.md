# 스크립트 생성 템플릿 (볼트 → script_*.js)

> 볼트 설정을 **견고한 스크립트로 "뽑는" 공장.** 이 템플릿에 볼트 칸을 끼우면 일관된 대본이 나온다.
> 관련: [[세계관]] · [[지은]] · [[지은-S4]] · [[조건-시스템]]
> 산출물 형식 = `src/data/script_{id}_s{n}.js` (turns 배열)

## 0. 원칙
- **대화 본진은 스크립트.** 볼트는 이 생성을 위한 재료. (Groq 실시간은 보조)
- 생성 후 **반드시 사람 검수** → 캐릭터 깨짐/반복/장소오류 잡기.
- 한 스테 = **11턴 × 선택지 3개**, 각 선택지 `affChange` 차등.

## 1. 입력 매핑 (볼트 칸 → 프롬프트)
| 프롬프트 슬롯 | 볼트 출처 |
|---|---|
| 캐릭터 핵심 | [[캐릭터]] core(욕망/두려움/방어) + 목소리 + 트리거(fav/weakness) |
| 현재 장면 | [[02_스테이지]] 장소/룩/**정서 곡선(연기지시)** |
| 준모 | [[세계관]] 주인공 설정 |
| 출력 형식 | 아래 3번 |
| 함정 설계 | 캐릭터 weakness → 마이너스 선택지 |

## 2. 생성 프롬프트 (복붙용 골격)
```
너는 한국어 연애 비주얼노벨 작가다. 아래 캐릭터/장면 설정으로 한 스테이지 대본을 쓴다.

[캐릭터] {이름}
핵심 심리: {core}
목소리: {voice 말투·침묵}
통하는 것: {fav} / 식는 것(함정): {weakness}

[이 장면] {장소}, {시간/무드}
연기 지시(정서 곡선): {스테 mood/정서곡선 — 시작→전개→고조→여운}
룩: {헤메코}

[준모] 29살 모태솔로, 진솔하지만 서툼. 속마음을 솔직히 노출.

[작성 규칙]
- 11턴. 각 턴: 장면지문 1줄 + 선택지 3개.
- 선택지 3개는 결이 달라야: ①진심/정답형 ②무난형 ③서툴거나 함정형.
- 함정(=식는 것 건드림)은 affChange 마이너스.
- {이름}답게만. 핵심 심리·연기지시에서 벗어나지 마. 같은 표현 반복 금지.
- 한국어만. 게임/AI 언급 금지.
- 정서가 턴이 갈수록 곡선을 그리게(평탄 금지).

[출력 형식: 정확히 이 JS 구조]
{ turn, scene, choices:[{text, response, affChange}] } 의 배열.
response 안에 "{이름}: 대사" / "준모: 대사" / "준모 속마음: ..." 줄들.
```

## 3. 출력 형식 (실제 코드 구조)
```js
export const {KEY} = {
  partnerId: "{id}", stageId: {n},
  opening: "...",
  turns: [
    { turn: 1, scene: "...", choices: [
      { text: "...", response: `{이름}: "..."\n준모: "..."\n준모 속마음: (...)`, affChange: N },
      ...3개
    ]},
    ...11턴
  ],
};
```

## 4. 검수 체크리스트 (생성 후 필수)
- [ ] 캐릭터 핵심 심리/목소리 유지 (안 깨짐)
- [ ] 장소·룩이 [[02_스테이지]]와 일치
- [ ] 선택지 3개 결 다름 + affChange 차등(함정 마이너스 포함)
- [ ] 정서 곡선 있음(시작→고조→여운)
- [ ] 반복 표현 없음 / 한국어만 / 형식 정확

## 4-B. 검수 반영 필수 규칙 (2026-06-28, 지은 S1 T2 피드백)
실제 플레이 검수에서 나온 **구조 결함 6종 → 강제 규칙화**:
1. **메아리 금지**: 속마음이 직전 대사의 단어/내용을 반복·요약하면 안 됨. (예: 대사 "침묵" → 속마음 "침묵으로…" ❌)
2. **속마음 = 감정/서브텍스트**: 결론·캐릭터 콘셉트 선언 금지. *대사가 안 해준 말*(당황·낯섦·미세한 끌림)을 줘라. 특히 첫 만남은 결론 X.
3. **준모 자동대사 최소화/중립화**: response 안에 준모 *대사*를 박지 마라(플레이어 페르소나와 충돌). 준모 목소리는 선택지(text)로만. 자동은 짧은 중립 리액션/행동만 허용.
4. **템포(한 박자씩)**: 한 response에 화자 셋(지은·준모·속마음) 욱여넣지 마라. response는 **짧게**(지은 1~2줄 + 속마음 1줄). 미니 대화 통째 X.
5. **선택지 = 직전 대사 받기**: 선택지는 직전 지은 대사의 화제/결을 이어야 함. 동문서답(갑자기 자기소개 점프) 금지. 최소 1개는 직전 결을 받아라.
6. **페이싱(명장면 아끼기)**: 깊은 통찰/명대사는 신뢰 쌓인 **중후반(T6~)**에. 초반은 워밍업(장소·커피·어색한 첫인사). **affChange 초반 작게**(첫 만남 T1~3은 +2~+7), 후반에 커지게. 2턴에 깊은 통찰+고호감 금지.
