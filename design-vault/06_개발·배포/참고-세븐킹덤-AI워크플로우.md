## 🔑 핵심 방법론 — AI 3개 역할 분담 + 교차 검증

**AI 하나로 다 하지 않고 셋을 역할로 쪼갠다:**

| AI | 역할 | 하는 일 | 주의 |
|---|---|---|---|
| **제미나이** | 친구 | 초안 던지기·아이디어 수렴 | 좋은 말만 해줌 → **믿으면 안 됨** |
| **클로드** | 선생님 | 엄격한 검증·수정 (별5개 될 때까지) | 창작보다 **검증**에 씀 |
| **커서** | 프로그래머 | 게임 시스템 호환·자동화 | 게임 전체 맥락 앎 |

> ⭐ **우리 재작성 실패의 해답**: 우리는 클로드(나) 하나가 **초안+검증을 다 하려다 맛이 죽었다**. 다카르트는 **초안(제미나이) ↔ 검증(클로드)을 분리**해서 이 문제를 애초에 없앤다. → [[플레이-피드백-수집]] 분석 참조.

## 📖 원문 핵심 (개발일지 4 · 2026.05.03)

### 1. 세계관/캐릭터 '바이블'을 세 AI에 기억
- 에이전트 만들 때 **바이블 문서 업로드 + "모든 기준은 이 문서에서 시작"** 명시.
- 캐릭터·사건 추가 시 **반드시 이 문서 기반**으로 진행·평가·검토.
- 바이블 내용: 세계·국가 연표(요약) / 히로인·주인공 요약표 / 주요 NPC·조직 / 주인공과의 관계 / 캐릭터 간 관계.
  - → 우리 [[개발-서사-원천]] + `01_캐릭터/` 볼트가 이 '바이블' 역할.

### 2. 작업 순서: 제미나이 → 클로드 → 커서
- **제미나이**: '친구'에게 막 던지듯 초안. 아이디어 수렴. (좋은 말만 하니 맹신 금지)
- **클로드**: '선생님'에게 엄격 검증. 평가받고 부분 수정, **별5개 될 때까지**. 마지막엔 **본인이 직접 읽고 디테일 수정**.
- **커서**: '프로그래머'. 시스템·환경 기반 조언. 게임 전체를 알아서 **시나리오를 게임에 맞게 정리** + 시스템 충돌 검토. 완성되면 **바로 빌드 반영해 테스트하며 수정.**

### 3. 커서 자동화 (핵심 효율)
- 만들어진 내용을 **커서가 바이블에 자동 정리** (다음 작업 때 제미나이·클로드에 갱신 필요하니까).
- 스크립트화, 오타·문법 교정 자동.
- **감정표현 이미지 자동 배치**: 표정 이미지 10장을 폴더에 넣고 "본편 적용, 이미지는 이 폴더에" 한마디 → 시나리오 내용·감정 분석해서 **울고 웃는 장면에 맞는 표정을 스크립트에 자동 삽입.** 일일이 고를 필요 없음.

### 4. 프로젝트 스케일 (이 자동화 덕분)
- 1인 개발, 캐주얼 미연시: **히로인 15명 · 1인당 60장 이미지 · 4~5만자 에피소드 · 풀보이스.**
- 현재 15명 중 9명 완성.

## 🎯 우리 적용 방안 (초안 · 도입 시 확정)

1. **초안/검증 분리**: 대사 초안은 다른 AI(제미나이 등)나 사람이 뽑고, 나(클로드)는 **검증·구조·일관성**에 집중. (통째 재작성 실패의 근본 대응)
2. **바이블 = 볼트 고정**: [[개발-서사-원천]]·캐릭터 시트를 '바이블'로 두고 모든 초안이 여기서 출발.
3. **positive spec 보강 필요**: 다카르트도 '검증(클로드)'을 쓰지만, 그 전에 '친구(제미나이)'가 맛을 냄. 우리는 지금 **검수(금지)만 있고 작법(지향)이 없음** → 작법·선택지 게임설계 문서 추가해야 초안 품질이 산다.
4. **커서 자동화 참고**: 표정 이미지 자동 배치 = 우리 `scenes.js`/표정 슬롯 수작업을 자동화할 여지.

## 📖 편별 핵심 (4편 외)

### 개발일지 (3) · no=381 — PV 영상 제작 (전 리소스 AI)
"모든 리소스를 AI로 제작한다고 박고 시작." 인디크래프트용 PV 제작 과정:
1. **게임 영상**: 그래픽카드 내장 캡처. 1분 미만으로 짧게 여러 개 찍어야 편집 시 구간 찾기 쉬움.
2. **BGM = SUNO**: 제미나이로 음악 프롬프트 뽑고 → SUNO에 붙여 2~3회 시도, 최적 선택.
3. **편집 = Final Cut**: BGM 먼저 깔고, 영상 클립을 **음악 박자에 맞춰** 컷 전환. "기교 없이도 괜찮은 영상."
4. **AI 영상 = Kling**: 왕국 전경·히로인 클로즈업. 배경 이미지 넣어 5~10초 생성.
5. **AI 보이스 = 슈퍼톤**: 히로인 대사 음성 + **립싱크 자동**.
6. 화이트아웃·페이드 마무리.
> 우리 적용: BGM(SUNO)·트레일러 만들 때 그대로 참고 가능.

### 개발일지 (5) · no=400 — 캐릭터 이미지 제작 워크플로우
- GPU: RTX 5090 (1024×1536 10초, 2048×3072 25초).
1. **기본 디자인 = ComfyUI 무한 생성**("금발·파란눈·웨이브" 외형) → 선별.
2. **업스케일 = IP-Adapter**로 고해상도.
3. **표정·포즈 = "제미나이 나노 바나나" 또는 "GPT 덕테이프"**에 원본 올리고 "당황·부끄러움·놀람·웃음" 프롬프트.
4. **일관성 = 포토샵**으로 얼굴/몸 크기 조정 + IP-Adapter 재생성.
5. **이벤트 씬 = 액션 프롬프트** 무한생성 → 배경 제거 후 게임 배경 합성.
> 팁: 복잡한 갑옷은 일관성 어려움. 평상복은 ComfyUI만으로 충분.

### 개발일지 (6) · no=403 — 캐릭터 복장 업그레이드
- 미오(고양이 수인) 복장 재설계. **"이미지 캐릭터 디자인·복장·화풍 그대로 4가지 표정+포즈 다양하게 그려줘"** 프롬프트.
- 도구: **"덕테이프"**(나노 바나나보다 우수 평가). → composite 재입력해 최종.

### 개발일지 (7) · no=412 — 진행 상황(캐릭터·스토리)
- AI 워크플로우 언급 적음. 신규 캐릭터·스토리·굿즈(캔배지 1000개, 아크릴 스탠드) 중심.
- 참고: 모녀 선택지 분기 = **심의 문제로 폐기**.

### 개발일지 (8) · no=468 — AI 보이스 작업
1. 스크립트에서 **대사 추출**.
2. **슈퍼톤(Supertone)**: "스크립트 가져오기"로 TXT 불러와 30자/5초 미만 생성.
3. 어색하면 **음높이·속도 조절** 후 개별 재생성.
4. 음성 파일을 폴더 저장 → 스크립트에 자동 적용.
> 팁: 히스토리 관리 + 저렴한 반복 생성. 초기작은 숙련 후 재작업. **게등위 심의**: 15명 중 6명 먼저 완성, 모든 파일 별도 제출.

### 개발일지 (9)~(11) · no=492·552·594 — 게등위 심의·행정 (AI 노하우 적음)
- (9) 심의 전략: 성인게임은 조작 상호작용 때문에 심의 까다로움 → **6명 먼저 등급받고 나머지 추가 심사**, 용량 줄여 심사비 절감. "커서에게 심사빌드 리소스 리포트 요청"(AI 어시 활용 암시).
- (10) H씬 100여 장 모자이크 확대·체액 제거. 아크릴 1,750개 납품. **클로에 보컬 OST**(보컬로이드 스타일).
- (11) 등급심사 접수(빌드 500MB, 심사비 36만원, 15세). 스토브 페이지·데모 예정. → **행정 위주, AI 노하우 없음.**

### 개발일지 (12) · no=623 — 캐릭터 이미지 (효율화)

### ⭐ 개발일지 (14) · no=738 — 문서 자동화·AI 기획 (핵심)

- **스크린샷 좌표 자동표기**: 게임 스샷을 폴더에 넣으면 **AI가 이미지 분석해 좌표를 달아** HTML에 자동 추가.
- **AI 기획 활용**: 게임 밸런싱·난이도를 AI에 제안 요청 후 개선.
> 우리 적용: 볼트를 md+HTML 이중 관리 / AI에 밸런싱(호감도 수치 등) 제안받기.
