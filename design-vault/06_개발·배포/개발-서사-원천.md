## ⚠️ 정본 팩트 (틀리면 안 되는 것)

- **현재 대화 방식 = 완전 스크립트.** 3인 × 5스테이지 = **15개 대본 전부 손으로 작성**되어 있음(`src/data/script_*.js`).
- **LLM(Groq)은 지금 사실상 안 쓴다.** 코드에 `callGroq`가 남아있지만, 자유입력창이 `{!isScripted && ...}` 조건이고 모든 스테이지에 대본이 있어 `isScripted`가 항상 true → **정상 플레이에서 LLM은 호출되지 않는 죽은 경로**다.
  - ❌ "대본 + LLM 자유입력 하이브리드" (현재형으로 쓰면 거짓)
  - ✅ "LLM으로 시도했다가 한계 보고 **완전 스크립트로 갈아엎었다**" (실제)
- 스테이지당 대본 길이 = **11턴** (`MAX_TURNS=20`은 옛 상한 잔재, 실제 종료는 대본 소진 기준).
- 1인 개발, 무료 웹 플레이, 한국어.

## 🎬 서사 뼈대 (배포 글 공통 골격)

### 1. LLM만 믿었다가 깨진 착각
LLM에 캐릭터 설정만 주고 대화시키면 될 줄 알았다. 몇 턴 못 가 무너진다: 성격 드리프트, 방금 한 말 까먹기, 뭘 쳐도 다 받아줘서 '공략' 게임성 소멸. llama·qwen 등 범용 모델로는 한국 소개팅 특유의 밀당·온도차가 안 나왔다. 캐릭터AI·제타 급 몰입을 기대했지만 근처도 못 감.

### 2. 방향을 뒤집었다 — 완전 스크립트로
자유대화를 포기하고, 히로인별 스테이지마다 **11턴 대본을 손으로 다 썼다.** 선택지별 호감도 증감·상대 반응을 미리 설계.
- 왜: 품질 일정 + 로딩 없음 + API 비용 0원.
- (LLM 자유입력 레이어는 코드에 흔적만 남고 실사용 폐기)

### 3. 대사보다 캐릭터 '심리'부터 설계
대본 앞에서 손이 안 나갔다 → 캐릭터가 누군지 몰라서. 대사 전에 욕망/두려움/방어기제부터 정함. 세 명을 정반대 축으로 안 겹치게. (아래 [캐릭터] 참조)

### 4. AI가 (초기에) 써준 대사를 감독처럼 검수
- 예: 관찰자가 첫 만남 2턴에 "당신은 침묵으로 사람을 보는군요" → 처음 본 사람한테 부담. 삭제.
- 규칙: 주인공 대사 자동생성 금지(플레이어 몫) / 속마음 창엔 결론 금지, 대사가 못 한 감정만 / 명대사는 후반으로.
- 어긴 대사는 어색함 점수·이유·수정안으로 리포트. (검수 기록: [[05_검수]] 폴더)

### 5. 호감도 밸런싱
초기엔 선택지 1개에 10~20씩 붙어 2턴 만에 '완전 설렘' → 비현실적. 전체 수치 재설계, 잘 골라도 마지막 턴에야 클리어 문턱.

### 6. 겪은 버그
- **스테이지 안 넘어감**: 대본 11턴인데 종료 조건이 '20턴'뿐 → 교착. '대본 소진 시 종료' 추가로 해결.
- 엔딩에 다른 캐릭터 얼굴: 셋이 옛 이미지 하나 공유 참조.
- 빨리 짜면 뭘 왜 고쳤는지도 빨리 잊음 → 버그마다 증상·원인·수정 기록.

### 7. 결론
프롬프트보다 **설계와 검수**에서 갈렸다. AI는 손이 빨랐지 뭐가 좋은지는 몰랐고, 그 판단은 사람 몫이었다.

## 🛠 기술 스택

React(CRA) · Vercel 배포 · localStorage(→Supabase 예정). Groq(llama-3.3-70b)는 fallback 경로로 코드에 남아있으나 실사용 X. API 키는 서버 함수 `api/chat.js`로 보호.
