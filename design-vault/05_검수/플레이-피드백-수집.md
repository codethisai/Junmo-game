## 수아 S1 (첫 만남 · 연남동 카페)

**T3~T4 구간**
- 준모 **속마음 대사가 인위적** — 예: "농담처럼 던졌는데, 답을 기다리는 눈치다" 류. 입체감 없음.
- **선택지가 대놓고 오답 유도** → 게임성 전혀 없음. **전면 수정 필요.**
- **외로움 소재를 너무 갑자기 꺼냄** — 수아 "왜, 외로워 보여요?" = 갑분(갑자기 분위기) 외로움. 인위적 전개.

**T5**
- 수아 대사 **"제가 맛집 좔좔인데"** 표현이 에바(과함/어색). "맛집" 소재가 T3부터 반복돼 더 어색.

**T6**
- 준모 속마음 **"슬쩍 자기 세상에 날 끼워주려 한다"** = 겁나 인위적, 표현 어색. 수정 필요.
- 선택지 **"안 꾸며도, 지금 충분히 좋은데요"** — 의도는 알겠는데 어색함.
- **선택지가 게임성에 도움 되게 전면 수정 필요** (반복 지적).

**T7**
- 수아 **"보통 소개팅 30분이면 지루한데"** — 소개팅 끝날쯤에 이런 속내를 지금 꺼내는 **타이밍이 어색**. 표현도 어색.
- 선택지 **"오늘부터 우리 1일인 거죠?"** — 첫 만남에 1일, **급전개로 어색**.
- 표현 전반이 여전히 어색.

**T9**
- 수아 **"내일 말고… 그냥 또 봐요 우리"** — 여기 이르는 **서사·빌드업이 너무 없음**. 갑자기 급호감.
- 준모 속마음 **"'또 보자'를 자기가 먼저 말했다"** — 준모 반응도 갑자기.
- **3안 선택지 수정 필요** (반복).

### 총평 (수아 S1) — 문제 유형별

**🔴 1. 급전개 (빌드업 없이 감정 몰아침)**
- T4 외로움 갑툭튀 / T7 끝날쯤 속내+"오늘부터 1일" / T9 "또 봐요 우리" 급호감

**🔴 2. 준모 속마음 인위적 (결론·티나는 서술)**
- T4 "답을 기다리는 눈치다" / T6 "슬쩍 자기 세상에 끼워주려 한다" / T9 "'또 보자'를 먼저 말했다"

**🔴 3. 선택지 게임성 없음 (특히 3안 = 오답유도)**
- T4·T6·T9 반복 → 전면 수정

**🔴 4. 표현 어색**
- T5 "제가 맛집 좔좔인데"(맛집 소재 T3부터 반복) / T6 "안 꾸며도 충분히 좋은데요"

> **결론: 수아 S1 전면 재작성.** 방향 = 첫 만남답게 수아는 텐션으로 띄우고 속은 평가·간보기 단계(외로움·1일 등 깊은 감정은 후반 S3~S5로). 준모 속마음은 결론 빼고 감정만. 선택지 3개 다 그럴듯하되 수아 성향(텐션·진정성)에 따라 차등, 대놓고 오답 금지. 호감도 천천히 → 마지막에 겨우 문턱.

## 지은 S1 (첫 만남 · 연희동 북카페)

**T2**
- 지은 **"전 그냥 따뜻한 아메리카노요. 늘 그거라."** — 표현 자체보다 **맥락 없이 뜬금포로 끼워맞춤** (갑자기 커피 취향).
- 선택지 **"공대 나와서 일해요… 사람 만나는 건 서툴러요"** — **갑자기 공대?** 뜬금없는 자기소개.
- 준모 속마음 **"취향이 확실한 사람인가. 단순한 게 편해 보인다"** — 결론적 서술(수아와 동일 문제).
- 이하 등등 **전면 수정 필요.**

**T3**
- 지은 "…서툴다고 먼저 말하는 사람은 드물어요" — 단편 스샷만으론 판단 어려움. **게임 들어가 앞뒤 문장 진행 보고 개선할 것.**
- 선택지 **"무슨 책이에요?"** — 갑자기(뜬금).
- 준모 속마음 "분위기가 조금 풀린 것 같다" — 결론성.

**T5**
- 지은 "네, 좀. (옅은 한숨) 그래서 나오는 것도 오랜만이에요." — 문장 자체는 문제없음. **앞뒤 서사가 문제.**
- 선택지 3개(가만히 둔다 / 조용하네요 / 질문 주고받을까요) — **게임성 요소가 없어서 흥미가 떨어짐.**

**T6**
- 지은 (창밖을 본다) 준모 속마음 "말이 없는데… 생각보다 안 어색하다"
- **선택지가 대화 내용과 전혀 관련 없음.**
- **정답/오답이 뻔히 티나는 문장들** (3번 "가끔은 핫플도 가줘야죠!"가 지은 지뢰인 게 대놓고 보임).

**T7**
- 지은 "…저, 원래 사람 많은 데 잘 안 가요. 여기처럼 조용한 데만." (자기 얘기 꺼냄)
- **스토리 갈아엎을 거라 대화내용은 참고만.**
- 선택지 "지은님은 말보다 사람을 좀 보는 편이세요?" — 어색.
- 선택지 "저 어때요? 합격이에요?" — 오답유도인 건 알겠으나 **3안에 기준도 없고 문장도 별로.**

**T7~8 ("말 안 해도 안 불편" 대사)**
- 지은 "…이상하네요. 처음 본 사람인데, 말 안 해도 안 불편한 거." — **첫 만남에 과한 친밀, 어색** (수아 T7 "30분이면 지루한데"와 같은 급전개 문제).
- 준모 속마음 "그 말을, 좀 더 듣고 싶다" — 이것도 어색.
- 선택지("고마워요 지치셨을 텐데" / "분위기 안 깨고 둔다" / "우리 잘 통하는 것 같지 않아요?") 전면 수정 참고.

**돌발 이벤트 (옆 테이블 커플 언성)**
- ⚠️ **UI 문제**: 상황 제시(이벤트 설명)와 선택지 **말풍선 스타일이 똑같아 구분이 안 됨.** → UI에서 이벤트 지문 vs 선택지 시각 구분 필요.
- 선택지 **"저 분들… 괜찮으려나. 우리는 저렇게는 안 싸워요."** — 첫 만남인데 **'우리'로 커플 전제? 어색.**

**T9**
- 지은 "…천천히 걷네요." 대사와 선택지 "또… 봐도 될까요?"가 **문맥 연결 전혀 안 됨.**
- 준모 속마음 "보폭 맞춘 걸 알아챈 것 같다" — **수아 S1 T5와 겹침**(재사용 흔적).

### ⚠️ 지은 루트 총지시 (유저)
- **지은은 문장뿐 아니라 스토리 자체가 전면 수정 대상. S1~S5 전부.**
- 스샷 단편 말고 **각 스크립트 전체를 읽고 앞뒤 맥락으로** 개선.
- 지은 정본([[지은]] · [[jieun-route-concept]]): INFJ 관찰자, 진솔함 신앙, 안 읽히려 함, 아는 척·진부한 질문 혐오. S1 낮음단계 = 차갑게 거리·책으로 벽. → 뜬금 자기소개·급전개가 캐릭터와 특히 안 맞음.
