# 검수 리포트 — 수아 S5 (남산 야경·진솔 피날레)

> 루브릭 = 6규칙 + [[수아]] 보이스/아크. 대상: 옛 `script_sua_s5.js`. 선행: [[수아-S4-검수]].

## 총평 (장소부터 틀림)
- **🔴 장소 완전 오류**: 컨셉/이미지 = **남산 케이블카·야경**(`sua_s5_cablecar_finale`/`sua_neutral_finale`, 호감≥60 분기). 그런데 스크립트는 **준모 집·할머니·반지·결혼·며느리·침실**. 피날레 무대가 통째로 틀림.
- **준모 자동대사 ~27** / **함정 0개**(전부 +19~20) / **메타·"모태솔로 27년"·반지·결혼·침실** 도배.
- 호칭 "당신" 전면.

## 아크 (피날레 의도)
S3(가면 벗기)·S4(가족 온기)를 거쳐, S5 = **수아가 '관심'이 아니라 '사랑'을 택하는 마무리.** 화려함·전시·빠른 텐션을 내려놓고, 화면 밖의 자기를 사랑받는 평생 소원을 이룸. 약속 = 결혼이 아니라 **"천천히, 오래"**(그녀가 늘 빨리 식던 것의 반대).
- 호감≥60 = 따뜻한 케이블카 피날레(smile) / <60 = WINDOW_NIGHT(neutral, 씁쓸). 분기는 씬 시스템이 처리하므로 스크립트는 남산 피날레 톤으로 일관.

## 처방
1. 준모 자동대사 제거. 호칭 "오빠". 메타·반지·결혼·며느리·침실·"모태솔로 27년" 전부 삭제.
2. **배경 = 남산 케이블카 → 전망대 야경.** 할머니·집 등장 안 함.
3. **피날레 비트**: 오늘은 카메라 안 켬 → "좋아요=사랑인 줄 알았는데 아니더라" 고백 → "화면 밖에서도 빛난다" 받아들임 → "천천히, 오래" 약속. (수위 포옹까지.)
4. 함정 유지: 순간 콘텐츠화·라이브 켜기·변화 부정·성급한 평생·다그쳐 확답·진심에 농담 = 음수.
5. affChange: 피날레라 정답 +11~+15, 함정 음수~중간.
