- **🔴 결혼 폭주**: 할머니가 **반지** 줌 → 프로포즈·"며느리"·"결혼하기로 했어요" 영상 발표·**침실로 감**. 4스테에 결혼 완결 = S5(피날레) 소진 + 게임 톤(소개팅) 초과.
- **준모 자동대사 20개** / **함정 0개**(전부 +18~20) / **메타 "Stage 5·최종" 다수**.
- **오타·깨짐**: "준모 속마심"(속마음) 반복, "눈을 떤다".
- 호칭 "당신" / 할머니 "마지막 소원" 신파.

## 아크 (S4 의도)
S4 = "가족·약속". 핵심은 **늘 혼자였던 수아(28만 팔로워인데 명절도 혼자)가 준모 가족의 소박한 온기에 닿는 것.** 결혼이 아니라 **소속감·집밥·정.** [[수아]]의 외로움(S3 고백)이 가족 온기로 **채워지기 시작**하는 단계. "약속"=또 오겠다는 가벼운 약속.
- 이미지 `sua_*_grandma`(한옥 마당·감나무·보라 머리띠+아가일 베스트)와 일치시킬 것.

## 처방
1. 준모 자동대사 제거. 호칭 "오빠". 오타·메타·신파 제거.
2. **반지·프로포즈·결혼·며느리·결혼 영상·침실 전부 삭제.** S4 = 한옥집 따뜻한 오후(집밥·툇마루·할머니 정).
3. **감정 비트 = 소속감**: "저 혼자예요(명절도 혼자)" → 할머니 "그럼 인제 여기 오면 되지" → 수아 울컥. 집밥 한 끼에 그동안의 허기가 드러남.
4. 함정 신설: 집을 콘텐츠화(찍기)·할머니 정성 거절(다이어트)·건성 대답·따뜻함 가볍게 퉁침·끝까지 사진 욕심 = 음수.
5. **T11 = S5(남산) 데이트 약속**으로 연결. 가라앉았던 텐션이 둘의 다음을 그리며 살아남.
6. affChange: 정답 +8~+12, 함정 음수.
